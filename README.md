# רגע · זמן עברי ואזרחי

שכבת התמצאות בזמן: מציגה יחד את התאריך האזרחי והעברי, מבינה באיזה רגע של היום היהודי אתה נמצא, ומסבירה מה חשוב עכשיו ומה המעבר הבא.

העיקרון: **רגע אחד עם שתי קואורדינטות** — בשקיעה מתקדם התאריך העברי, בחצות האזרחי. אף מערכת לא נעלמת.

## הרצה

```bash
npm install
npm run dev        # שרת פיתוח — http://localhost:5173
npm run build      # בנייה ל־dist/ — אתר סטטי מוכן לפריסה
```

`dist/` הוא אתר סטטי טהור: אפשר להעלות ל־GitHub Pages / Netlify / כל שרת, או לשלוח לחבר (שיריץ `npx serve dist`). אין תלות בשרת, בחשבון או ב־API חיצוני — **כל הלוח מחושב מקומית** בעזרת [@hebcal/core](https://github.com/hebcal/hebcal-es6), לכל שנה שהיא.

## מצב בדיקה — זמן מדומה

כדי לבדוק את הממשק מול רגע מסוים (ליל צום, ערב שבת, בין השמשות):

```
http://localhost:5173/?t=2026-07-22T21:30
```

השעון ימשיך לרוץ מאותה נקודה. מופיע חיווי "מצב בדיקה" בתחתית.

## ארכיטקטורה

```
src/
  engine/          המנוע — בלי UI בכלל
    moment.ts      תמונת־רגע: קואורדינטות, שלב היום, שכבות, מעברים
    layers.ts      אילו שכבות חלות בתאריך עברי נתון + דירוג עיקר/מצטרף
    zmanim.ts      זמני היום לפי מקום (עטיפה ל־hebcal)
    calendar.ts    רשתות חודש (אזרחי/עברי) ופרטי יום
    periods.ts     תקופות: בין המצרים, ספירת העומר, אלול...
    cities.ts      ערים, קואורדינטות, דקות הדלקת נרות
  content/         שכבת התוכן — קובץ לכל מועד
    model.ts       המבנה: תמצית / מה־עכשיו לפי שלב / ציר זמן / למעשה / רקע / מנהגים / מקורות
    tisha-bav.ts   ...עמוד לכל מועד; כל פסקה מתויגת: דין / מנהג / היסטוריה / ממלכתי
  ui/              המסכים: עכשיו, חודש, יום, עמוד מועד
```

### עקרונות

- **המנוע לא יודע על הממשק** — כל מסך הוא תצוגה של `makeSnapshot(now, city)`.
- **תוכן מתויג** — כל פסקה מסומנת דין / מנהג / מנהג קהילות / היסטוריה / ממלכתי / הערה. המערכת מציגה מידע, לא פוסקת הלכה.
- **שקיפות כיסוי** — מועד בלי עמוד כתוב מקבל עמוד אוטומטי מהנתונים המחושבים, עם ציון שהעמוד המלא בהכנה.
- **זמנים** — צאת הכוכבים לפי 8.5°; הדלקת נרות: ירושלים 40 דק', חיפה 30, שאר הערים 20 (הנחת ברירת מחדל, יהיה ניתן להתאמה).
- **לוח ארץ ישראל** (`il: true`) — תמיכה בחו"ל היא הרחבה עתידית מובנית.

## הוספת עמוד תוכן חדש

1. צור `src/content/<slug>.ts` לפי המבנה של `tisha-bav.ts` (ה־slug נגזר משם האירוע ב־hebcal: `Tu BiShvat` ← `tu-bishvat`).
2. הוסף אותו ל־`src/content/index.ts`.
3. זהו — המנוע יקשר אליו אוטומטית מכל מקום שהמועד מופיע.

## מה הלאה (כיווני המשך)

- עוד עמודי תוכן (חגי תשרי, חנוכה, פורים, פסח, ימים לאומיים)
- ייצוא iCal — הרשמה מהיומן הקיים (גוגל/אפל)
- התראות חכמות לפי שלב (ערב, כניסה, בוקר)
- הגדרות נוסח/עדה והבדלי חו"ל
- Service Worker לעבודה מלאה אופליין (ה־manifest כבר קיים)
